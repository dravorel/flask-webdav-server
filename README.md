# Flask WebDAV Server

Лёгкий WebDAV-сервер на Python с использованием Flask. Позволяет организовать удалённое файловое хранилище и управлять файлами и директориями через протокол WebDAV.

Сервер поддерживает загрузку, скачивание, удаление, копирование, перемещение файлов и управление директориями. Все данные хранятся локально в директории `storage/`.

## ✨ Возможности

- **HTTP Basic Authentication** — защита доступа с помощью логина и пароля.
- **Управление файлами** — загрузка, скачивание и удаление файлов.
- **Управление директориями** — создание и удаление директорий.
- **Копирование и перемещение** — поддержка операций COPY и MOVE.
- **Поддержка WebDAV** — реализация основных методов протокола WebDAV.
- **PROPFIND** — получение информации о файлах и директориях в формате XML.
- **ETag** — генерация уникальных тегов для ресурсов.
- **Определение MIME-типа** — автоматическое определение типа файлов.
- **Защита файловой системы** — предотвращение выхода за пределы директории хранилища.
- **Потоковая загрузка** — передача файлов частями.

## 🔧 Поддерживаемые методы

| Метод      | Описание                                                      |
|------------|---------------------------------------------------------------|
| `OPTIONS`  | Получение списка поддерживаемых методов и возможностей WebDAV |
| `GET`      | Скачивание файла или просмотр содержимого директории          |
| `HEAD`     | Получение HTTP-заголовков ресурса                             |
| `PUT`      | Загрузка или перезапись файла                                 |
| `DELETE`   | Удаление файла или директории                                 |
| `MKCOL`    | Создание директории                                           |
| `PROPFIND` | Получение свойств файлов и директорий                         |
| `COPY`     | Копирование файла или директории                              |
| `MOVE`     | Перемещение или переименование файла или директории           |

## 📋 Требования

- Python 3.10+
- Flask

## 🛠️ Установка

1. Клонируйте репозиторий
    ```bash
    git clone <URL>
    cd <project-directory>
    ```

2. Создайте виртуальное окружения
    ```bash
    python -m venv .venv
    ```

3. Активируйте виртуальное окружение
    ```bash
    source .venv/bin/activate  # Linux / MacOS
    .venv\Scripts\activate     # Windows
    ```

4. Установите зависимости
    ```bash
    pip install -r requirements.txt
    ```

## ⚙️ Настройка

Создайте файл `.env` в корневой директории проекта:

```env
USERNAME=admin
PASSWORD=your_secure_password
```

## ▶️ Запуск

Для запуска сервера выполните:

```bash
python app.py
```

По умолчанию сервер будет доступен по адресу:

```text
http://127.0.0.1:5000
```

## 💻 Примеры использования

Для взаимодействия с сервером также можно использовать `curl`.

### Получение списка файлов

```bash
curl -u admin:your_secure_password \
     -X PROPFIND \
     -H "Depth: 1" \
     http://127.0.0.1:5000/
```

### Загрузка файла

```bash
curl -u admin:your_secure_password \
     -T example.txt \
     http://127.0.0.1:5000/example.txt
```

### Скачивание файла

```bash
curl -u admin:your_secure_password \
     -O http://127.0.0.1:5000/example.txt
```

### Создание директории

```bash
curl -u admin:your_secure_password \
     -X MKCOL \
     http://127.0.0.1:5000/documents/
```

### Удаление файла

```bash
curl -u admin:your_secure_password \
     -X DELETE \
     http://127.0.0.1:5000/example.txt
```

### Копирование файла

```bash
curl -u admin:your_secure_password \
     -X COPY \
     -H "Destination: http://127.0.0.1:5000/copy.txt" \
     http://127.0.0.1:5000/example.txt
```

### Перемещение файла

```bash
curl -u admin:your_secure_password \
     -X MOVE \
     -H "Destination: http://127.0.0.1:5000/moved.txt" \
     http://127.0.0.1:5000/example.txt
```

## Безопасность

- Для защиты доступа используется HTTP Basic Authentication.
- Пути к файлам проверяются на попытки выхода за пределы хранилища (Path Traversal).
- Все файловые операции ограничены директорией `storage/`.
- При доступе через недоверенные сети необходимо использовать HTTPS.
- Не рекомендуется публиковать встроенный Flask-сервер напрямую в интернете. Для production-развёртывания следует использовать WSGI-сервер, например Gunicorn, совместно с обратным прокси.
- Рекомендуется ограничить права операционной системы на директорию хранилища.

> [!NOTE]
> Проект представляет собой лёгкую реализацию WebDAV для личного 
> использования, локальных сетей и небольших развёртываний. 
> Он не реализует все возможности полной спецификации WebDAV.
